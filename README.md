An Excel-based dashboard for tracking sales team performance across regions.

## What's inside

- **Raw data** – daily sales figures (Day 1–5) for each sales executive, along with region, total sales, and target values.
- **Dashboard view** – pivot tables summarizing:
  - Total sales by executive
  - Total sales by region
  - Target hit % by executive
  - % away from target by executive

## How to use

1. Download `Dashboard_project_day_10.xlsm`.
2. Open in Excel (macros enabled, since it's a `.xlsm` file).
3. Update the **Raw data** sheet with new entries.
4. Refresh the pivot tables to update the dashboard automatically.

## Tools used

- Microsoft Excel (Pivot Tables, Formulas)
